# 🌟 Virtual Pet Simulator, Mood-Based Background & Plant Growth Simulator

Three beginner-friendly, pure HTML + CSS + JavaScript projects. Free for educational purposes.

---

## 🎭 1. Mood-Based Background

**Folder:** `mood-background/`

The user selects a mood and the background changes with a matching emoji and message.

- 😊 Happy → Bright background + positive message
- 😢 Sad → Calm background + encouraging message
- 😴 Tired → Relaxing background + rest message
- 😡 Angry → Calm message + peaceful background

**Skills:** Event listeners, CSS transitions, DOM manipulation.

### Files
- `index.html`
- `style.css`
- `script.js`

---

## 🌱 2. Plant Growth Simulator

**Folder:** `plant-simulator/`

The user takes care of a virtual plant by watering it and giving it sunlight to watch it grow.

- 💧 Water the plant
- ☀️ Give it sunlight
- 🌱 Watch it grow through stages
- 📊 Track growth percentage

**Growth stages:** Seed → Sprout → Small Plant → Mature Plant 🌳

**Skills:** JavaScript conditions, progress bars, functions, CSS animations.

### Files
- `index.html`
- `style.css`
- `script.js`

---

## 🐶 3. Virtual Pet Simulator

**Folder:** `virtual-pet/`

A digital pet named Buddy that the user can care for.

- 🍔 Feed the pet
- 🎮 Play with the pet
- 😴 Let it sleep
- 😊 Track happiness and energy
- 💬 Display different messages based on the pet's condition

**Skills:** Variables, functions, buttons, conditions, DOM manipulation.

### Files
- `index.html`
- `style.css`
- `script.js`

---

## 🚀 How to Use

1. Open any project folder.
2. Open `index.html` in a browser.
3. Interact with the buttons.

No build tools or frameworks required.
